### What is this
LA-arrows.py is a fork of the arrows.py repository by kala telo, enhanced to support new features introduced in version 5 of the save files. This library enables the use of hidden features present in the game [Logic Arrows on Steam](https://store.steampowered.com/app/4210250/Logic_Arrows/).

You can find examples of how to use the library in the project's "examples" folder.
